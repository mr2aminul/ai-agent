# AI Project Agent - API Documentation

## Overview

The AI Project Agent uses a Flask backend with SQLite3 database for data persistence and file operations. The system provides REST APIs for managing projects, conversations, messages, workplans, and file operations.

## Database

### SQLite3 Database

The application uses SQLite3 for all data persistence. The database file is stored at `./project_agent.db` by default (configurable via `PYTHON_DB_PATH` environment variable).

**Database Tables:**
- `projects` - Project metadata
- `conversations` - Chat conversations
- `messages` - Chat messages
- `workplans` - Work plan definitions
- `tasks` - Individual tasks from workplans
- `patches` - Code patches generated by LLM
- `file_operations` - Track file operations performed

## File Operations API

### Read File

```
POST /api/files/read
Content-Type: application/json

{
  "project_path": "/path/to/project",
  "file_path": "src/index.ts"
}

Response:
{
  "success": true,
  "content": "file contents here...",
  "path": "/full/path/to/file",
  "size": 1234
}
```

### Write File

```
POST /api/files/write
Content-Type: application/json

{
  "project_path": "/path/to/project",
  "file_path": "src/newfile.ts",
  "content": "file contents...",
  "overwrite": true
}

Response:
{
  "success": true,
  "path": "/full/path/to/file",
  "size": 1234,
  "message": "File created: src/newfile.ts"
}
```

## Frontend Integration

The frontend provides a TypeScript client library for easy integration:

```typescript
import { createFileClient, getProjects, createProject } from '@/lib/fileOperations';

// Get all projects
const projects = await getProjects();

// Create a new project
const result = await createProject('My Project', '/path/to/project');

// Create file client for a project
const fileClient = createFileClient('/path/to/project');

// Read a file
const content = await fileClient.readFile('src/index.ts');

// Write a file
await fileClient.writeFile('src/newfile.ts', 'file content');

// List directory
const files = await fileClient.listDirectory('src');

// Search files
const results = await fileClient.searchFiles('*.ts', 'src');
```

## Security Considerations

### Path Traversal Prevention

All file operations include path validation to prevent directory traversal attacks. Paths are resolved relative to the project root and must remain within the project directory.

### Data Validation

All API endpoints validate input parameters and return appropriate error messages for invalid requests.

### File Operations Constraints

- Files must be read/written within the specified project directory
- Directory traversal using `../` is prevented
- Symbolic links are followed but still checked for boundary violations

## Error Handling

All API responses include a consistent error format:

```json
{
  "success": false,
  "error": "Description of what went wrong"
}
```

HTTP Status Codes:
- `200` - Success
- `400` - Bad Request (missing or invalid parameters)
- `500` - Server Error
